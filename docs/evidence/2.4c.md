## (a) What changed

| Commit | Summary |
|---|---|
| `cd776ea` | `agentos/llm/router_llm.py`: `AgentOSRouterLLM` (CrewAI `BaseLLM`). Tries providers in policy order (enabled flags, timeouts) with vault-first keys and supports native function calling and ReAct. Tool calls still run through the proxy-wrapped functions, and a blocked tool call is never retried on another provider. Emits a metadata-only record per call (provider, model, attempts, tokens, latency). T-13: secret-labelled input goes only to local providers, otherwise the call is refused. `router_factory.py` adds `model_info` (provider, key env, local). |

The docs note covers 127.0.0.1, `REQUIRE_API_KEY=true`, upstream terms and prompt logging. `export_vault_provider_keys()`: vault secrets named like provider key variables are loaded at app start (the vault wins over env, and only names are returned). `app.py`: lifespan export plus the `AGENTOS_UI_DIST` override. |
