## (d) Known gaps and deviations
- **CI not run / no PR yet:** `gh` is not authenticated on this machine and the branch is not pushed. CI result and PR link pending (section f).
- **FastAPI is still loaded at runtime by `import agentos`**, transitively through CrewAI (`crewai/a2a/auth/server_schemes.py`). Our own code does not import it (AST test). Not fixable on our side without dropping or patching CrewAI; recorded for the Executor work in Phase 2.
- **Plan deviation:** the plan had the wheel install as a `slow` pytest test; it is a script + CI job instead, so offline runs do not raise the skip count.
- **Plan deviation:** server tests moved with unchanged contents (they import via `agentos.server.app`, so they double as shim tests).
- `check_system.py` imports a module-level `app` from the server module, which has never existed (factory only). Pre-existing; only the import path was updated.
- `main.py` still binds `0.0.0.0`. Localhost binding is scoped to 1.4 by the plan.
- Wheel dependency set: wheel users now get the core deps but not torch/transformers/faiss/chromadb/psycopg2/streamlit/pytest unless they ask for extras. Previously they got nothing (broken install), so no working install loses anything. Adapters for those backends import lazily and fall back with a warning.
