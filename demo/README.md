# demo

This is an autogenerated AgentOS multi-agent project.

## Structure
- `agentos.config.yaml`: Project configuration, tags, and defaults.
- `agents/`: Agent configuration YAML files.
- `tools/`: Custom Python tool implementations.
- `mcp_plugins/`: Third-party addon plugin packages.
- `crews/`: Crew orchestrators.
- `missions/`: Mission definitions (task lists).
- `checkpoints/`: Local run state database for checkpointing.

## Usage
Run a mission: `agentos run . --mission <mission_name>`
